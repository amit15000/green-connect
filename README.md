# 🌱 Green Connect

**Green Connect** is a modern, responsive frontend web application built entirely with **React**, **Vite**, and **Tailwind CSS**. The project promotes environmental awareness by providing a beautiful and fast user interface to showcase eco-friendly ideas and content.

🔗 **Live Demo**: [https://green-connect-red.vercel.app](https://green-connect-red.vercel.app)

---

## 🌟 Features

- ⚡ Lightning-fast performance using Vite
- 🧩 Component-based design with React
- 🎨 Styled with Tailwind CSS utility classes
- 🧭 Smooth navigation using React Router DOM
- 📱 Fully responsive and mobile-friendly UI
- ☁️ Deployed seamlessly on Vercel

---

## 🛠️ Tech Stack

- **Framework**: React + Vite
- **Styling**: Tailwind CSS
- **Routing**: React Router DOM
- **Deployment**: Vercel

---

## 🚀 How to Run Locally

Follow these steps to clone, install, and run the project on your local machine:

```bash
# 1. Clone the repository
git clone https://github.com/amit15000/Green-Connect.git
cd Green-Connect

# 2. Install dependencies
npm install

# 3. Start the development server
npm run dev

```

# Build optimized files
npm run build

# Preview production build locally
npm run preview
